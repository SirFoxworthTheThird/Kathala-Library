PlotWeave Library

This is not a website. It is where PlotWeave fetches the books in its Library, so a new one reaches readers without waiting for a new version of the app.

Thirty-nine worlds built from published books. Thirty-one carry the complete text of a public-domain novel, each naming the Project Gutenberg edition it was built from; the rest are structural references to books still in copyright and contain none of their text.

The catalogue is at /library/index.json, and each world sits beside it.

Open PlotWeave and choose Library to read one. The books are unofficial references, not affiliated with any author or publisher.

Source, and how to add a book: github.com/SirFoxworthTheThird/PlotWeave-Library
