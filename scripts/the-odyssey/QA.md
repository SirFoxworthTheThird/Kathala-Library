# The Odyssey artwork review

This replacement contains 31 distinct original illustrations: a new cover and 30 narrative scenes. The four map layers remain linked for geographic reference. The generated files retain the existing PWK image IDs, so chapter, lore, character, location and faction references continue to resolve.

## Visual direction and review

The set uses a consistent Bronze Age Aegean setting, painterly tempera and fine ink, and Aegean blue, terracotta, ivory and muted gold. All 31 PNG masters were inspected on three contact sheets. The bow scene was regenerated after the first review because Odysseus was not the focal actor; the final version shows him using the bow before the suitors. The rebuilt contact sheet and final image were checked before conversion.

Prompts are recorded in `PROMPTS.md`. PNG masters are local review artifacts; the compact JPEGs and contact sheets are committed. `validate.mjs` checks the 31 artwork blobs, four maps, resolved image references, JPEG integrity, unique file hashes, source archive and catalogue byte count.
