# The Wise Man's Fear artwork review

This replacement contains 37 distinct original illustrations for the 37 externally linked non-map image records. The existing PWK image IDs remain in place so characters, items, locations, lore, factions and cover references continue to resolve. Eleven map layers remain linked for geographic reference.

## Visual review

All 37 PNG masters were inspected on four contact sheets for subject, composition, visual consistency and unwanted text. The set uses original ink and watercolor scenes in indigo, amber, burgundy and moss green, matching the companion set for *The Name of the Wind*. The ground-dwelling draccus, cover image, character portraits and main locations were checked individually in the sheets. No image required regeneration.

Prompts are recorded in `PROMPTS.md`. PNG masters are local review artifacts; the compact JPEGs and contact sheets are committed. `validate.mjs` checks all image references, the 37 local JPEGs, eleven maps, unique file hashes, the archived sources and catalogue byte count.
